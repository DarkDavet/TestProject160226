It is a test project where I implemented a view model of a slot machine.

## Technical description
* Unity Version: 6000.0.31f1
* Render Pipeline: URP
* Tools: AxGrid, FSM 

## Project structure
* Assets/TASK3 - a folder with all scripts, assets, prefabs of the project

## How to launch?
1. Clone the repository
2. Open the project in Unity (6000.0.31f1)
3. Open and run the scene Assets/TASK3/Scenes/TASK3_Scene.unity
